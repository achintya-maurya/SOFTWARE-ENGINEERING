# Smart City Civic Complaint and Management System

## Project Overview

The Smart City Civic Complaint and Management System is a web-based
platform designed to streamline the reporting, tracking, assignment,
and resolution of civic complaints.

The system connects citizens, department officers, field workers,
and administrators through a structured complaint management workflow.

## Problem Statement

Citizens often face civic issues such as potholes, garbage accumulation,
water leakage, sewage problems, broken streetlights, and damaged public
infrastructure.

The proposed system provides a centralized platform through which these
issues can be reported, tracked, assigned, resolved, and verified.

## Key Features

- Citizen registration and login
- Civic complaint submission
- Photo and location upload
- Complaint tracking
- Officer verification
- Worker assignment
- Complaint status updates
- Before/after evidence
- Citizen resolution verification
- Complaint reopening
- SLA monitoring
- Notifications
- Analytics and maps
- Smart complaint classification
- Duplicate complaint detection
- Priority assistance

## User Roles

- Citizen
- Department Officer
- Field Worker
- Administrator

## System Workflow

Citizen reports a complaint
→ Complaint classification
→ Priority calculation
→ Department assignment
→ Officer verification
→ Worker assignment
→ Work execution
→ Evidence upload
→ Resolution
→ Citizen verification
→ Complaint closure

## Technology Stack

- Frontend: React
- Backend: Python + FastAPI
- Database: PostgreSQL
- Smart/AI Layer: Python, scikit-learn and NLP libraries
- Version Control: Git / GitHub
